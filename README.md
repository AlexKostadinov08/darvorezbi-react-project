# Дърворезби - React SPA

Изпитен проект за курса ReactJS в SoftUni.

## Дизайн

За визията реших да не измислям нищо ново, а да използвам дизайна на моя
истински сайт - [darvorezbi.com](https://darvorezbi.com), онлайн магазин за
ръчно изработени дърворезби. Там вече имах готова дизайн система: топла
палитра в орехово и слонова кост, шрифтове Playfair Display за заглавията и
Manrope за текста, общи отстояния и сенки.

Пренесох я от WordPress темата в обикновени CSS файлове, така че проектът
не зависи от WordPress по никакъв начин. Страниците, които сайтът няма
(каталог с търсене, форми за вход и регистрация, коментари, 404 и т.н.),
ги стилизирах наново в същия стил.

### Къде какво е

| Файл | Какво съдържа |
|---|---|
| `src/styles/fonts.css` | Шрифтовете - хостнати локално в `public/fonts/` |
| `src/styles/tokens.css` | Дизайн токените - CSS променливи `--dr-*` за цветове, шрифтове и отстояния |
| `src/styles/base.css` | Малък reset, базова типография и достъпност |
| `src/styles/ui.css` | Общи елементи (`.dr-*`) - контейнер, бутони, съобщения за грешка, зареждане, празно състояние, 404, модален прозорец |
| `src/styles/forms.css` | Формите (`.dr-form-*`, `.dr-field`) - вход, регистрация, добавяне и редакция |
| `src/components/header/Header.css` | Хедърът (`#dh`, `.dh-*`) |
| `src/components/footer/Footer.css` | Футърът (`.df-*`) |
| `src/components/comments/Comments.css` | Коментарите (`.cm-*`) |
| `src/pages/home/Home.css` | Началната страница (`.drh-*`) |
| `src/pages/catalog/Catalog.css` | Каталогът (`.dc-*`) - търсене, филтри и карти |
| `src/pages/details/Details.css` | Страницата на едно изделие - горна част с харесване и бутони за автора (`.dd-*`) и описание (`.pd-*`) |

Глобалните стилове се зареждат веднъж в `main.jsx`, а всеки компонент си
импортира своя CSS файл. В началото на всеки файл има кратък коментар с
пример как се използват класовете.

## Докъде съм стигнал

Дизайнът е избран и стиловете за всички страници са готови. Следващата
стъпка е React частта - routing и layout, регистрация и вход, каталог и
детайли, CRUD операциите, бекенд и deploy.

## Как се пуска

```bash
npm install
npm run dev
```

След това приложението е на `http://localhost:5173`.
